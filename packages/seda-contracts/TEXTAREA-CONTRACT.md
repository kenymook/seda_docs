# D30 — исполняемый TextArea

TextArea добавляется как общий native textarea в public SEDA package для комментариев и composer сложных приложений. Его profile и component colors читаются из существующих `text-area` tokens, без новых значений tokens.json. Контракт фиксирует native textarea, обязательный непустой label, native disabled/readOnly, errorText и description composition.

`value:string` + `onChange` задают controlled ownership; readOnly/disabled допускают controlled value без callback. `defaultValue:string` — uncontrolled; value/defaultValue взаимоисключаются. children и dangerouslySetInnerHTML исключены из API и отклоняются runtime: они не могут задавать скрытый третий источник значения в обход counter/clear. Clearable controlled требует отдельный onClear; callback хозяина решает, принять ли очистку. Uncontrolled clear меняет native value и уведомляет onClear, а не имитирует React ChangeEvent. Native form reset восстанавливает defaultValue, filled/counter и высоту. Controlled reset принадлежит форме.

`rows` — положительное целое, default3. `autoResize` по умолчанию false; ручной resize vertical или none. Ручная высота сохраняется при вводе и перерисовках; переход к autoResize передаёт владение высотой компоненту, возврат к ручному режиму снимает только auto-owned inline height. При autoResize browser resize отключён, maxRows (если есть) целое >=rows; без autoResize maxRows отклоняется. Высота первой строки берётся из shared control height H; дополнительные строки добавляют shared line-height L. Минимальная внешняя высота `H+(rows−1)*L`, padding по Y `max(0,(H−L−2B)/2)`. Для autoResize измеряется native scrollHeight и применяется cap `maxRows*L+2P+2B`; после cap прокручивается сам textarea. X добавляется к shared padding-inline, Y меняет первую строку, темы/размеры не меняют значение и selection. Для маленького текста сохраняется минимум rows; CSS может меняться по общему профилю. Численные тесты относятся к проверенным browser/runtime, не к универсальному typography engine.

`hideLabel` скрывает видимый label, сохраняя его accessible name, для composer. `showCount` информирует о native UTF-16 length/maxLength, с изолированным LTR направлением числа даже в RTL, без live announcements на каждую клавишу. Error precedence: disabled подавляет ошибку и использует helper; readOnly сохраняет выделение/копирование и может показывать ошибку. Focus ring независим от error/readOnly, одна рамка вокруг control; counter и error description не заменяют label.

Enter, Shift+Enter и composition остаются native событиями: TextArea ничего не отправляет сам. Composer обязан отдельно проверять isComposing и свою submit policy. Неизвестные варианты/props/token paths не поддерживаются. AutoResize и clear/counter/hidden label — документированные runtime behavior additions для существующих anatomy/boolean slots, не произвольные visual variants. Figma node2187:3331 из spec не прошёл отдельную текущую визуальную приёмку; её нельзя выводить из browser/contract tests. Screen reader, другие engines и desktop shell требуют отдельных фактических проверок.
