# Sidebar: общий навигационный компонент — 25.10.2026

Files и Chat используют public experimental Sidebar установленного @seda-ai/ui вместо своих навигационных ссылок, padding и selected styles. Общие token roles, control profiles, исходные glyphs и размерные параметры объединяют навигацию с остальной библиотекой. Ширина, routes, история, создание проектов, поиск, сохранение и async state принадлежат прежним приложениям.

Компонент различает native link и owned action, группирует пункты семантически, поддерживает full/collapsed с настоящими Tooltip и controlled disclosure. Current route сохраняется при сворачивании группы; disclosure показывает current-location cue и название скрытого route. Пустые группы имеют объяснение, loading требует status text. Фокус восстанавливается локально при удалении/скрытии пункта и смене full; внешний фокус не перехватывается. Навигация скроллится отдельно от header/footer.

Публичные props и причины добавления описаны в specs/navigation/sidebar.md. Sidebar использует existing component tokens, tokens.json не изменён. Provider profile generation включает Sidebar, чтобы native ссылки и Button действительно получали один size fallback. Отдельный executable instance contract ещё не добавлен; registry остаётся11. Библиотека теперь содержит28 component entry modules/35 runtime exports — это не28 production-ready компонентов.

Визуальный проход нашёл обрезание поиска/нижней кнопки длинным списком: flex-basis исправлен, header/footer сохраняют содержимое и собственную прокрутку. Browser focus test обнаружил Tooltip, который пропускал focus, восстановленный родителем до подключения listener: общий Tooltip теперь проверяет уже сфокусированный trigger. Скриншотные baseline не переписывались.
