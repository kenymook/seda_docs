# Popover: общий контекстный host

Статус: experimental реализация в рабочей ветке; опубликованный сайт остаётся version51. Цель зрелости всей системы не завершена.

Добавлен настоящий установленный Popover для коротких nonmodal flows. Files news и Chat share используют общие Button/IconButton/Text/TextField и исходные icons; модели данных, clipboard и JSON export сохраняют владельцев. Controlled open/close, outside focus, Tab без trap, Menu/Modal hierarchy, clipped trigger, dynamic focus repair, collision и compiler inheritance принадлежат host. Search overlay composition проверяется отдельно, без замены существующего Chat Modal.

Первоначальный installed React18 preflight прошёл192 selected geometry/theme/density cases и11 invalid models, без browser errors; gallery просмотрена Light/Dark. После расширения negative/focus-repair/Search composition checks требуется повтор и полный package/application прогон точного source. Предварительный успех не объявлен release proof.

API и причины props, реальные token paths и geometry gaps описаны в specs/feedback/popover.md. tokens.json не менялся; registry по-прежнему11 executable control contracts. Новый export не равен component maturity. Fresh Figma service quota, platform/AT review и instance contract остаются открытыми.

Расширенный installed React18 preflight прошёл192 selected cases и14 invalid models; дополнительно Search overlay host, dynamic focus repair, surface/control size independence, native fallback, Modal/Menu hierarchy и текстовый контраст обеих тем. Short-window app test нашёл настоящий host defect: sticky Files toolbar перекрывал Read more при XL150/X24/Y12 в1024×480. В коротком desktop окне header теперь прокручивается с main; normal-height sticky behavior сохранено. Новый export test сначала ожидал всю базу чатов; фактический существующий owner экспортирует только активную переписку. Assertion проверяет ровно выбранный thread, version/origin и отсутствие остальных чатов; export implementation не менялась. Первый неверный вызов contrast helper также исправлен в verifier. Исходные отказы сохранены отдельно. Полный release run ещё не объявлен успешным.
