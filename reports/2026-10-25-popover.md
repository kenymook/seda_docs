# Popover и согласованность рабочих панелей

Опубликована приватная версия 52 по прежнему адресу. Files news и Chat share используют общий Popover из установленного @seda-ai/ui вместе с Button, IconButton, Text и TextField. Данные документов, сохранение, clipboard и экспорт выбранного чата остаются у существующих владельцев. Цель зрелости всей дизайн-системы остаётся открытой.

## Реализация

Controlled nonmodal host поддерживает именованную панель, описание, footer, логическое выравнивание, viewport collision, native top layer и fixed fallback. Начальный фокус, Tab без trap, возврат фокуса и outside-focus dismissal принадлежат host. Владелец может отклонить закрытие для несохранённого содержимого. При исчезновении/отключении trigger панель скрывается безопасно. Menu/Select/Popover/Modal закрываются отдельными нажатиями Escape; удержание клавиши не снимает следующий слой. Вложенный Popover пока запрещён.

Существующие10 цветовых token roles подключены к генератору CSS; tokens.json не изменялся. Surface size не зависит от плотности контролов. Для news/share выбрана ширина L400, общий ритм header/body/footer и существующие иконки. В коротких desktop окнах Files header прокручивается с содержимым: прежний sticky header перекрывал Read more. Авторские canvas/document размеры не подменяются параметрами оболочки.

## Визуальная оценка и границы

Просмотрены package gallery, actual Files/Chat, короткие окна и выбранные инспекторы в Light/Dark. Общие16/8/4 spacing recipes, оптический icon slot/foreground и масштабирование сохранены на остальных экранах. На экстремальной плотности рабочая область становится тесной и требует локальной прокрутки; прохождение geometry checks не означает удобство любой комбинации параметров.

Первые реальные отказы сохранены отдельно: sticky header, преждевременное закрытие Popover из native Select, held Escape через owning Modal. Ошибочные предположения verifier о textContrast helper и экспорте всей базы исправлены по действующему API/владельцу, без изменения export implementation. Прерванные до последнего Modal fix прогоны не считаются PASS; окончательные логи относятся к указанному runtime source. Screenshot baselines не переписывались.

Новый export остаётся experimental: нет executable instance contract для Popover, fresh Figma/AT/target OS/native IME/Firefox/WebKit/performance approval. Геометрия поверхности имеет документированные fallback gaps; variant labels не выданы за готовые emoji/avatar pickers. Общий public icon catalog пока неполон. Remote sharing/permissions и AI backend не симулируются. Предыдущее ограничение production Search automation с авторизацией native new tab не объявлено исправленным этим релизом.
