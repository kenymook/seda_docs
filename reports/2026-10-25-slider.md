# Slider: числовые параметры и диапазоны

Статус: experimental runtime в рабочей ветке; приватный сайт пока version52. Цель зрелости всей системы остаётся открытой.

Добавлен public controlled Slider по существующей spec: native single/range, неизменный Tab-порядок, значения без пересечения, реальные FormData/fieldset disabled и native thumb drag. Общий rail выбирает ближайший thumb и удерживает его на протяжении жеста. Четыре параметра Lab используют installed export и прежний compiler; range/error/disabled композиции вынесены на экран «Компоненты» с явной experimental отметкой. Registry сохраняет11 executable contracts; Slider instance contract пока отсутствует.

Предварительно installed React18 прошёл32 выбранных сочетания theme/size/width/RTL (в каждом single/range/decimal/large-offset fixtures),20 invalid models, SSR/Strict hydration, реальные keys/drag/form/owner refusal. Проверка большого смещения обнаружила потерю шага1 при значении1000000000000050 из-за toPrecision(15). Вместо принудительного округления используется целочисленная десятичная сетка там, где она безопасно представима, и raw representable arithmetic в остальных случаях. Повтор этого случая прошёл. Это не произвольная financial decimal арифметика.

Actual Lab preflight16 viewport/theme/profile сочетаний проверяет, что реальные действия по scale/X/Y/radius меняют compiler и геометрию React-компонентов; range state не теряется при смене параметров. Полный package/application повтор и новая публикация ещё не объявлены завершёнными.

Существующие slider color tokens подключены к CSS generator; tokens.json не менялся. Font, thumb/icon slot, control height и extra X наследуются от общих bindings. Геометрические fallback gaps описаны в [spec](../specs/inputs/slider.md). Свежая Figma/OS/AT/Firefox/WebKit/native touch assistive проверка, vertical API и instance contract остаются открытыми. API/state-count не выдан за зрелость всей библиотеки.
