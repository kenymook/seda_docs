# Общие иконки и плотность панелей — 25.10.2026

Files, Building и Chat используют public experimental TopBar из установленного @seda-ai/ui. Удалены отдельные локальные header layouts/paddings. Общие размер, X/Y, текст и исходные иконки применяются к верхним панелям; интерфейсы сохраняют собственные команды, навигацию, прокрутку и данные. Длинные Building breadcrumbs переносятся при увеличении масштаба. Files scrolled surface зависит только от своего main scroll.

TopBar поддерживает существующие четыре варианта, именованные слоты, native Link navigation и явный inline/dialog режим с настоящим Modal. Новые props и foundation geometry описаны в specs/navigation/top-bar.md. Registry остаётся11 executable instance contracts; 27 component entry modules/34 runtime exports не означают27 готовых компонентов.

Визуальная проверка нашла пустую иконку в тестовом примере: имя file отсутствует в исходном каталоге. Пример исправлен на monitor; Icon теперь отвергает неизвестные имена и prototype keys вместо маски url(undefined).25 исходных glyph assets не изменены. Raster-проверка требует нарисованные пиксели, а не один bounding box.

Выявленные и исправленные ошибки: локальный responsive padding Files перекрывал общий X; Building breadcrumbs выходили за панель на XL/150%/X24/Y12; RTL смена направления могла скрыть уже сфокусированный navigation item. Дефекты исправлены в соответствующем общем компоненте или его композиции. Тестовый Ctrl-click наблюдает новую страницу context (noopener), а не popup исходной страницы.

## Проверка

- TopBar installed consumer:96 выбранных сочетаний (360/1000 px,2 темы,S/M/L/XL,80/100/150%,inline/dialog), native destinations, disabled, RTL, focus return, responsive collapse и draft persistence. Loading при изменении X/Y/масштаба: Δwidth=0, Δheight=0 px в целевом сценарии.
- Реальные headers:72 выбранных сочетания (Files/Building/Chat ×960/1440/1920 ×2 темы ×4 профиля). Проверены applied padding, bounds и отсутствие page overflow, неизменность авторского текста Building, draft Chat и scoped scroll Files.
- Снимки реальных экранов просматриваются в обеих темах. Проверка инспекторов охватывает8 приложений ×2 ширины ×2 темы ×5 профилей; painted glyph evidence и независимые functional suites выполняются отдельно.

Финальные результаты полного прогона, CI и публикации добавляются после завершения; зелёный результат заранее не заявляется.
