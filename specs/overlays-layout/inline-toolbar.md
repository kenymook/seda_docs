## Назначение и применение

InlineToolbar собирает короткие действия рядом с редактируемым выделением в плотном рабочем приложении. Он отвечает за общую поверхность, порядок фокуса и клавиатурную навигацию. Приложение отвечает за выделение, позицию, команды, историю и сохранение. Используйте SEDA Button или IconButton с доступными именами внутри. Для длинного списка команд используйте DropdownMenu или Search; для постоянной панели приложения — TopBar.

Компонент не выполняет форматирование сам и не интерпретирует содержимое редактора. Вложенные компоненты сохраняют собственные варианты и токены; toolbar не задаёт им частные цвета или радиусы.

## Anatomy, состояния и размеры

| Часть | Обязательность | Правило |
| --- | --- | --- |
| `root` | да | `role="toolbar"`, непустое доступное `label` |
| `actions` | да | Кнопки или ссылки с короткими именами; несколько действий остаются различимыми |
| `selection anchor` | в приложении | Приложение показывает toolbar только при валидном выделении и обеспечивает отсутствие перекрытия рабочих областей |

Поддержаны состояния `default`, `focus` вложенного действия, `pressed`/`disabled` через соответствующий SEDA Button. Контейнер принимает `size` S/M/L/XL и наследует размер SedaProvider. Нестандартный `compact` размер не вводится: общий масштаб текста, X/Y и размеры вложенных контролов продолжают действовать.

## Поведение и доступность

- При входе Tab активен один доступный action. Стрелки влево/вправо перемещают фокус по доступным действиям с циклическим переходом; RTL меняет направление. Home/End переходят к первому/последнему. Disabled actions пропускаются.
- Enter/Space остаются нативным действием вложенной кнопки. Название действия и `aria-pressed` для toggles передаёт приложение. Оно же возвращает фокус к выделенному тексту после команды, если это нужно для продолжения редактирования.
- Overlay placement, коллизии, clipping, selection loss и responsive поведение принадлежат приложению. Сам компонент не телепортирует toolbar и не меняет документ.
- В forced colors граница остаётся видимой. Screen reader/OS приёмка ещё требуется; браузерная проверка клавиатуры не заменяет её.

## Токены и код

Контейнер использует существующие semantic tokens `surface.raised`, `border.subtle`, `text.primary`, `shadow.overlay`, общий control radius и font family. Вложенные действия используют свои component tokens. Отдельных component tokens InlineToolbar в `tokens.json` пока нет — **Token gap** перед переводом в стабильный статус.

```tsx
import {InlineToolbar, Button} from '@seda-ai/ui';

<InlineToolbar label="Форматирование выделенного текста">
  <Button variant="ghost" aria-label="Жирный" aria-pressed={bold} onClick={toggleBold}>B</Button>
</InlineToolbar>
```

Props: `label` обязателен; `children` — действия; `size` опционален и наследует SedaProvider; стандартные атрибуты `div` и ref доступны. Не добавляйте выдуманные `position`, `selection`, `format`, `onFormat` или несуществующие токены.

## Handoff и приёмка

Приложение должно доказать: выделение внутри одного владельца; команды изменяют документ только по явному действию; undo/reload сохраняют форматирование; работа мышью и клавиатурой; возврат фокуса; Light/Dark, S–XL, X/Y, узкое окно без перекрытия; неподдержанные диапазоны и повреждённые marks отклоняются. Для Building пример находится в `portal/component-lab/pilots/settings-parametric/references/building.tsx`; исходный Figma frame не содержит состояния открытого toolbar, поэтому его визуальное поведение отдельно проходит review.

## AI usage rules и anti-patterns

AI может использовать только описанные props, состояния и токены; отсутствующие token mappings и accessibility evidence обязан помечать как **Needs system review**. AI не должен придумывать вариации или записывать HTML редактора как доверенный код. Handoff и критерии может подготовить AI, но решение о ready статусе требует человеческой проверки. Антипаттерны: общий контекстный toolbar поверх заголовка/текста; пустое доступное имя; icon-only action без имени; изменение текста при открытии панели; локальный цвет каждого вложенного Button.
