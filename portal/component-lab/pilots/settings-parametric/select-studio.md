# Select: настройка и сравнение состояний

В Component Studio живой Select дополнен девятью фиксированными визуальными образцами на том же публичном @seda-ai/ui: default, hover, focus, disabled, error, warning, success, read-only, loading. Цвета берутся из существующих компонентных токенов. hover/focus фиксируются только внутри образцов CSS-привязками для сравнения; это не новые состояния или props библиотеки. Нативный список по-прежнему зависит от ОС.

Часть выбирается под живым образцом или через Property group. Это навигация: меняется список свойств инспектора, уже открытый popover закрывается, новый автоматически не открывается. Редактор цвета открывается явно нажатием на цветовую роль справа. Нажатие на название состояния открывает его токен в выбранной части; если отдельного токена в ней нет, используется border этого состояния. Назначение роли компонентному токену не меняет саму семантическую роль. В popover показана область изменения и есть переход «Открыть общую роль»; там показывается число и список зависимых токенов для текущей темы.

«Отменить изменение» возвращает предыдущее значение последнего локально изменённого токена; изменение снова проходит существующее автосохранение. Если значение уже заменено внешним обновлением, отмена недоступна, чтобы не перезаписать более новую правку. История отмены относится к текущему сеансу, одно действие. «Вернуть исходное значение» удаляет override выбранного токена. Остальные токены не сбрасываются.

Отмена — публичный SEDA IconButton с иконкой undo справа в заголовке инспектора компонентов, с aria-label и tooltip. Повторные подписи имени компонента, SEDA UI и статус над холстом убраны. Статус успешного сохранения остаётся в aria-live без видимой подписи. Конфликты, offline и retry остаются в существующей модели сохранения; база и API не изменены.

## Границы

Исправление стрелки: сам публичный Select использует оригинальную SEDA arrow-chevron-down в отдельном декоративном слоте контрола. Нативная стрелка скрыта; слот пропускает pointer events и остаётся по центру при раскрытии. verify-select-arrow.mjs проверяет 9 случаев геометрии: Light/Dark × LTR/RTL с раскрытием плюс 5 размеров токена иконки. Отклонение центра допускается не более 0.5 px; размер контрола и отступ стрелки при раскрытии не меняются. verify-select-engines.mjs прошёл в установленном Chrome для Framer и Lab: клавиатура, Escape, сохранность фильтра и геометрии. Скриншоты закрытого Light и открытого Dark просмотрены визуально. Остальные движки в этой правке не запускались.

Пакетная проверка сначала прошла 21 группу React 18 и остановилась на устаревшем измерении удалённого ::picker-icon. verify-field-anatomy обновлён на измерение настоящего SEDA-слота, скрытия нативной стрелки и вращения glyph. Повторный запуск этой функции на установленном tarball: 48 cases, 432 field records, focus/caret/value retained, errors []. Полная матрица пакета React 18/19 после обновления теста повторно не запускалась. TypeScript, audited pilot/Worker builds, verify-select-studio и verify-token-editor прошли.

active пока остаётся без отдельного образца; readOnly/loading реализованы с блокировкой изменения и сохранностью формы; на холсте это явно отмечено. Автосохранение настоящей D1 уже проверялось в saved-design.md; в этой задаче протокол/API не изменялся и повторные тестовые записи в рабочую базу не выполнялись. Другие компоненты сохраняют прежние предпросмотры; перенос доски состояний на них — отдельная работа.
