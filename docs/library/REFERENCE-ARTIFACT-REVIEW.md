# Диалог и редактируемый артефакт — промежуточная проверка

Цель: проверить класс рабочего интерфейса «чат рядом с документом» на том же установленном пакете SEDA, не выдавая локальный образец ответа за AI-сервис или за готовый Claude Design. Это дополнительный сценарий существующего `/references/chat.html`, а не новая копия сайта или десятый Figma frame.

## Работающий сценарий

- Артефакт открывается рядом с перепиской в SEDA SplitView; разделитель меняет ширину с мыши и клавиатуры. При окне до 1280 px навигация скрывается, оставляя место для диалога и редактора.
- SEDA TextField/TextArea редактируют название и тело; SEDA Tabs переключают редактирование и безопасный текстовый preview. Текст не вставляется как HTML.
- Завершённый ответ может предложить текст артефакту. Предложение видно отдельно; существующий документ меняется только после «Принять». Ручная правка отменяет ожидающее предложение. Незавершённый потоковый ответ не предлагается.
- Явное сохранение создаёт версию. Старую версию можно восстановить в редакторе и сохранить заново. История ограничена 30 версиями. Артефакты изолированы по chat ID и сохраняются в браузере; повреждённая запись показывает восстановление вместо тихой замены.
- При ошибке записи состояние остаётся на экране, есть повторная попытка. Локальная модель отклоняет чужой thread ID, неверные версии и принятие предложения после изменения базы.

## Свидетельства

TypeScript и сборка прошли. `verify-chat-artifact.mjs`: 1 model и 4 browser группы, 0 ошибок; внутри браузерных групп проверены edit/preview/version/reload, принятие предложения, восстановление, переключение чатов, темы Light/Dark, XL/150%/X24/Y12, окно 1280, ошибка квоты и явное восстановление повреждённых данных. Исходный `verify-chat.mjs` отдельно прошёл 4 model и 12 browser групп. Это группы сценариев, не количество отдельных утверждений.

Ручной просмотр: [Dark 1440](../../portal/component-lab/pilots/settings-parametric/verification/chat-artifact-dark-1440-local.png), [Light XL 1440](../../portal/component-lab/pilots/settings-parametric/verification/chat-artifact-light-xl-local.png), [Light XL 1280](../../portal/component-lab/pilots/settings-parametric/verification/chat-artifact-light-xl-1280-local.png). Первый снимок показал обрезку длинной кнопки при XL; исправлены перенос подписи и минимальная ширина панели, после чего узкий вариант проверен повторно. Изображения — локальные свидетельства, не замена Figma baseline.

## Не закрыто

Нет AI provider, совместной работы, серверного сохранения, rich text, подсветки diff и построчного применения изменений. Исторические сообщения — исходный пример, новые ответы — локальный fixture. Для общего критерия ещё требуются визуальная приёмка, AT/OS/browser matrix, нагрузка длинного артефакта и полноценная проверка остальных рабочих экранов.
