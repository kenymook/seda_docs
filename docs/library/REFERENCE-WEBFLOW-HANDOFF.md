Статус: модель документа и изолированный DOM preview проверены; экран редактора ещё не собран и не опубликован. Это предметная логика приложения, не новый компонентный контракт SEDA.

## Реализовано

- Строгая сериализуемая модель: страницы, узлы, общие CSS-классы, четыре breakpoint-слоя. Разрешён ограниченный набор CSS-свойств и единиц; произвольный HTML, script, URL и custom CSS не исполняются.
- Desktop ≥992 px, Tablet 768–991 px, Landscape 480–767 px, Portrait 240–479 px. Стили каскадируют от Desktop вниз. Сброс удаляет только переопределение текущего слоя.
- Происхождение заданного значения: начальное значение → рецепт → родитель → класс/breakpoint. Заданное значение отделено от фактических CSS-размеров браузера.
- Нативное наследование относительных единиц. Унаследованный `2em` не записывается повторно на каждого потомка; unitless line-height остаётся нативным CSS.
- Изолированный iframe без разрешения скриптов; DOM создаётся через безопасные узлы и textContent. Нативные layout/grid/spacing/borders, редактирование текста, выбор кликом, измерения DOM и смена viewport.
- Документная история до 50 изменений. Save snapshot, блокировка повторного запроса, отмена/устаревшие ответы и повтор после ошибки записи. История не меняет параметры вида.

Начальные значения CSS являются явными defaults реконструированного документа. Они не должны позиционироваться как неизменённые browser defaults или токены SEDA. Геометрия canvas независима от масштаба текста и плотности интерфейса SEDA.

## Проверка

`npm run verify:webflow:domain` выполняет 12 групп модели и 8 групп изолированного браузерного preview. Результаты находятся в `verification/webflow-domain-local.json` и `verification/webflow-preview-local.json`; CI сохраняет свежие `.diagnostics-webflow/*.json` и PNG.

Покрытие: строгий импорт/циклы/прототипы, CSS units и недопустимые значения, каскад и reset, общие классы, наследование, атомарность команд, add/delete, undo/redo, save guards; реальный iframe, геометрия, vw/em, breakpoint/%, текст/escaping/выбор, line-height и независимость от host scale, visibility, grid/spacing/border/reset, dispose. Это 20 групп ограниченного охвата, а не 20 полных пользовательских сценариев и не приёмка экрана.

## До готовности экрана

1. Собрать React chrome из установленного SEDA: navigator, resizable panels, toolbar, tabs, fields/selects и inspector. Подключить точные source UI assets.
2. Связать выбор/стили/текст/viewport/zoom и измеряемый overlay одним документом; обеспечить черновики полей без потери фокуса и явную индикацию inherited/overridden/computed.
3. Реализовать реальное сохранение/восстановление модели, страницу/дерево, keyboard history, обработку ошибок и восстановление после reload. Preview остаётся без исполняемых embeds.
4. Проверить совместную работу installed SEDA, темы/размеры/X/Y/text scale, keyboard/фокус, loading, viewport и отмену операций. Дополнить визуальное сравнение с исходником и честно описать несовпадения.
5. Обновить PR и опубликовать только собранный и проверенный экран на существующем приватном Site с повторной проверкой production и доступа.

States/interactions/CMS/Insights/collaboration и внешний Webflow publish не реализованы. Локальный JSON export нельзя называть публикацией сайта. Полная цель, все 9 reference frames и классы Figma/Notion/ChatGPT/Claude Design остаются открытыми.
